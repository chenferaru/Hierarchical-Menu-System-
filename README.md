# Hierarchical Menu System

A modular and extensible console-based hierarchical menu system developed in C#. This project demonstrates the application of object-oriented programming principles to create dynamic, nested menus suitable for various console applications.

## Features

- **Hierarchical Structure**: Supports nested menus, allowing for organized and intuitive navigation.
- **Event-Driven Architecture**: Implements event handling to manage user interactions seamlessly.
- **Interface-Based Design**: Utilizes interfaces to promote modularity and ease of extension.
- **Testable Components**: Includes a dedicated testing project to ensure reliability and facilitate future enhancements.

## Technologies Used

- C#
- .NET Framework
- Object-Oriented Programming (OOP) principles

## Getting Started

### Prerequisites

- [.NET SDK](https://dotnet.microsoft.com/download) installed on your machine

### Running the Application

1. **Clone the repository**:
   ```bash
   git clone https://github.com/chenferaru/Hierarchical-Menu-System-.git
   ```
2. **Navigate to the project directory**:
   ```bash
   cd Hierarchical-Menu-System-
   ```
3. **Open the solution** in your preferred IDE (e.g., Visual Studio).
4. **Build and run** the `Ex04.Menus.Test` project to see the menu system in action.

## Project Structure

- `Ex04.Menus.Interfaces/`: Contains interface definitions promoting abstraction and modularity.
- `Ex04.Menus.Events/`: Implements event handling mechanisms for user interactions.
- `Ex04.Menus.Test/`: Provides test cases and examples demonstrating the menu system's capabilities.
